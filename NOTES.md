# SteamDeals: заметки для ассистента (состояние на 28.10.2026, после обновления №2)

## Что это и где живёт
Сайт скидок Steam для регионов UA (по умолчанию), US, KZ, RU. Владелец не программист, русскоязычный.
- Репозиторий: github.com/blessedqqx/SteamDeals (публичный, ветка main). Сайт: https://blessedqqx.github.io/SteamDeals/ (GitHub Pages, корень).
- Данные обновляет GitHub Actions: `update.yml` (раз в сутки 05:00 UTC, ~25-30 мин: discover, collect, reviews, build_pages) и `post.yml` (посты в Telegram).
- Telegram-канал: https://t.me/SteamDealsHOT. Секреты репозитория: `TG_TOKEN`, `TG_CHANNEL` (= `@SteamDealsHOT`).
- Cloudflare Worker (профиль Steam): https://steam-profile.night091643.workers.dev, ключ Steam API НЕ добавлен, поэтому блок профиля на сайте скрыт (`WORKER: ""` в config.js).

## Файлы
- `index.html`: весь сайт (один файл, чистый JS, переводы ru/uk/en в объекте `L`, распродажи Steam в `SALES`, русские алиасы поиска в `ALI`).
- `config.js`: настройки владельца (WORKER, TG_CHANNEL, TG_BOT). Владелец правит его на GitHub, поэтому в обновления кладите его только если меняете.
- `scripts/discover.py` (каталог: теги SteamSpy; SEED стартовых игр, бесплатные помечены `f`), `collect.py` (цены 4 региона, история, бесплатные, повтор по одной игре), `reviews.py` (отзывы + описания ru/uk/en + скриншоты + активность по месяцам; в конце вызывает `build_pages.py`), `build_pages.py` (data/g/*.html и data/sitemap.xml для поиска), `post_telegram.py` (один пост за запуск).
- `worker/index.js`: Cloudflare Worker (профиль, ключ Steam API необязателен, но без него профиль не работает: XML-адрес Steam мёртв).
- `data/`: генерируется Actions, руками не править и НЕ загружать из архива. В архиве лежит только games.json как пример.
- `tests/`: `bash tests/run.sh` (заглушки Steam/SteamSpy/Telegram, без интернета). `assets/`: иконки и аватарка.

## Решения и пожелания владельца
- Категории: жанры (сюжетные, кооператив, шутеры, открытый мир, хоррор, инди, гонки, стратегии); скидки «−50%» и «−75%» СТРОГО равные; «до N» в местной валюте (бесплатные в них не входят); исторический минимум; бесплатно (в каталоге есть популярные F2P).
- Без отдельной категории 18+ (игры с 18+ сценами допустимы). Исключаем только теги Hentai и NSFW.
- Сортировка по умолчанию «Популярные» (сначала игры со скидкой, внутри по числу отзывов).
- Окно игры: обложка и скриншоты, описание, цена, график цены, активность отзывов по месяцам (это не продажи, Steam их не публикует), оценка владельцев, подсказка «брать или ждать» (по накопленной истории и датам распродаж).
- Поиск понимает русские названия («киберпанк», «гта5», «баттлфилд»); нужные игры добавляйте в `ALI` и в SEED.
- Telegram: один пост на игру, цены во всех регионах в своих валютах, краткое описание, отзывы, хештеги, кнопки. Условия: скидка от 50% хотя бы в одном регионе, отзывы от 80% и от 5000. 5 постов в сутки (по одному в запуске, `post.yml`: 07:20, 10:20, 13:20, 16:20, 19:20 UTC).
- Иконка: простая надпись «SD» зелёными буквами на тёмном фоне (favicon.png, apple-touch-icon.png); аватарка канала: кольцо + SD + STEAM DEALS (assets/channel-avatar.png). Вариант «пар над ценником» владелец отверг. Логотип Steam не копируем (торговая марка Valve).

## Обновление №2 (28.10.2026), ещё не подтверждено владельцем
- Популярные игры: `discover.py` берёт топы SteamSpy (top100in2weeks/forever/owned) независимо от жанра и оценки (минимум 3000 отзывов), они не режутся лимитом MAX_TOTAL; жанр им определяется по тегам SteamSpy (до 60 игр за запуск, без жанра игра видна только в «Все»). BIG_REV снижен до 15000. В Telegram: `HIT_REV=50000`/`HIT_PCT=40`: игры от 50 тыс. отзывов проходят и с оценкой от 40%.
- Раздачи (скидка 100% на платную игру): чип «🎁 Раздача» (виден только когда раздачи есть), пометка на карточке, особая подсказка в окне; «Бесплатно» теперь только F2P. Telegram: пост «Раздача» идёт вне очереди и вне суточного потолка. Раздачи из списка специальных предложений Steam добавляются в каталог без проверки жанра. Раздачи НЕ пишутся в историю цен (иначе «минимум» навсегда станет 0).
- Избранное: ♡ на карточке и в окне игры, чип «♥ Избранное»; список хранится в браузере (localStorage), на другое устройство не переносится.
- «Лучшее сегодня»: до 6 игр над списком (скидка от 50%, оценка от 70% или от 50 тыс. отзывов и от 40%; раздачи первыми); скрыт при любых фильтрах/поиске.
- Счётчик: `CF_ANALYTICS` в config.js (токен Cloudflare Web Analytics); попадает и на страницы игр (`build_pages.py` читает config.js). Пока токен пуст, счётчика нет.
- Карта сайта теперь включает главную страницу. Search Console: владелец должен добавить сайт (префикс URL) и отправить `data/sitemap.xml`.
- Не проверено на настоящем Steam/SteamSpy: названия запросов top100* и поле discount_percent в featuredcategories (по документации; при ошибке в журнале будет «ошибка», остальное продолжит работать).

## Обновление №4 (29.10.2026), ещё не подтверждено владельцем
- Блок «Лучшее сегодня»: вместо полосы прокрутки круглые стрелки ‹ ›; правило отбора: оценка от 70% или (от 50 тыс. отзывов и от 40%).
- Светлая/тёмная тема: кнопка ☀/☾ в шапке, выбор хранится в браузере (localStorage `theme`); по умолчанию тёмная. Цвета вынесены в CSS-переменные (`:root` и `:root[data-theme="light"]`), салатовый акцент #7be0a4 общий для обеих тем. Страницы игр `data/g/*.html` остаются тёмными.
- Дата окончания скидки: `scripts/ends.py` (вызывается из collect.py) пишет `data/<регион>/ends.json` {id: unix}; источник Steam IStoreBrowseService/GetItems без ключа (поля `best_purchase_option.active_discounts[].discount_end_date`), по 50 игр за запрос. В окне игры строка «Скидка действует до …» (в часовом поясе браузера) и «осталось N дн.»/«меньше суток». НЕ проверено на живом Steam: если формат ответа другой, строки просто не будет.
- Telegram «Топ-5 скидок недели»: по воскресеньям в первом запуске не раньше 16:00 UTC (`WEEKLY_DAY`, `WEEKLY_HOUR` в post_telegram.py), раз в неделю, занимает место обычного поста.
- Анонсы распродаж: файл `data/announce.json` (id, date старта, days_before, approved, text; в тексте `{days}` и `{site}`). Бот не умеет «отложенную отправку», поэтому запуск по расписанию сам публикует анонс за days_before дней до старта (и позже, но до старта), только при `"approved": true`. Поставлен анонс зимней распродажи (17.12.2026 – 4.01.2027, даты Valve по нескольким источникам), approved = false до подтверждения владельца. Весенняя 2027: 18–25 марта, летняя: 24.06–8.07 (источник GameSpot), осенняя 2027 не подтверждена.
- Для тестов: переменная окружения SD_NOW подменяет время запуска post_telegram.py.

## Как работать с владельцем
Короткие шаги «куда нажать», по одному действию. Обновления: один zip, владелец распаковывает и перетаскивает файлы в GitHub (Add file → Upload files, папку `.github` браузер не загружает: её файлы создаются вручную через Add file → Create new file). Не просит и не принимает токены. На вопрос «почему так» отвечать простыми словами и честно, без выдумок.

## Подводные камни
- Песочница ассистента может потерять рабочую папку между сообщениями: восстанавливайте проект из присланного архива и перед выдачей запускайте `bash tests/run.sh` из свежей распаковки.
- В песочнице нет интернета: настоящие ответы Steam/SteamSpy/Telegram не проверены, только заглушки. Неофициальные адреса (SteamSpy tag, appreviewhistogram) могут измениться: смотреть логи Actions (шаги помечены continue-on-error, общая галочка зелёная и при ошибке шага).
- Steam отдаёт описания и скриншоты ограниченно (~100 игр за запуск), поэтому они появляются постепенно.
- «Совет брать или ждать» точен только после недель накопления истории.
- Даты распродаж в `SALES` обновлять раз в год.
